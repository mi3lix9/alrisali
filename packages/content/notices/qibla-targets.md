# Shrine coordinates

Source: the infobox coordinates of each shrine's Wikipedia article (listed in `src/qibla-targets/data/shrines.ts`), cross-checked against OpenStreetMap.

Licence: none needed. Latitude and longitude of a building are public geographic facts, which copyright does not cover. No text, image or database extract is used.

## What is used

- One coordinate pair for each of the Imam Ali Shrine (Najaf), Imam Husayn Shrine (Karbala), Imam Reza Shrine (Mashhad), the Prophet's Mosque (Madina), Al-Kadhimiya Mosque (Baghdad) and Al-Askari Shrine (Samarra), which the Qibla uses to give a direction and distance to each Shrine.

## Changes

- Degrees-minutes-seconds converted to decimal degrees and rounded to four places.
