# Thaqalayn — Books (Mafatih al-Jinan, Sahifa Sajjadiyya, Nahj al-Balagha)

Source: Thaqalayn (Stichting Thaqalayn), https://thaqalayn.com. Licence: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/ (Thaqalayn terms, §02, https://thaqalayn.com/terms#content-license). Not endorsed by Thaqalayn.

## What is used

- **Nahj al-Balāgha** (al-Sharīf al-Raḍī): Arabic text and English translation by Sayed Ali Raza, https://thaqalayn.com/book/32. Fetched through the ThaqalaynAPI project (https://github.com/MohammedArab1/ThaqalaynAPI): its API, or, when the API is down, the same project's published dataset of book 32. Sermons 1–241, letters 1–79 and sayings 1–480.
- **al-Ṣaḥīfa al-Sajjādiyya**: Arabic text and English translation of supplications 1–54 and the seven supplications for the days of the week, https://thaqalayn.com/duas. Thaqalayn does not record a translator for these pages.
- **Mafātīḥ al-Jinān**: Thaqalayn does not publish Mafatih al-Jinan as a book. The app's Mafatih al-Jinan holds the Mafatih duas and ziyarat that Thaqalayn publishes, Arabic and English, https://thaqalayn.com/duas: Dua Kumayl, Dua al-Sabah, Dua al-Iftitah, Dua al-Nudba, Dua al-Mashlul, Dua al-Asharat, Ziyarat Ashura, Ziyarat Warith, Ziyarat al-Arbaeen, Ziyarat Aal Yasin and Ziyarat al-Jamia al-Kabira. Thaqalayn does not record a translator for these pages. No other source is used; nothing comes from al-islam.org.

## Changes

- Reformatted to JSON for offline use, one file per Supplication.
- Whitespace collapsed; footnote markers (`[1]`) removed from Nahj al-Balagha, whose footnotes are not included; the leading item number removed from each Nahj sermon, letter and saying (the app shows the number).
- Nahj al-Balagha titles: the item kind and number, then, in English, Thaqalayn's chapter title (for example الخطبة ٣ / Sermon 3: Shaqshaqiya …).
